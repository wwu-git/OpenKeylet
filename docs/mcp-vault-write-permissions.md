# MCP 保险库写入权限设计

状态：方案已确认，待实现。

允许 Agent 通过 MCP 新增和修改 OpenKeylet 保险库项目，包括替换已有密码、Token 和 SSH 私钥。用户在桌面端配置允许写入的文件夹名称。这里的文件夹是保险库项目的分组字段。

## 权限规则

写入权限默认关闭，允许名单默认为空。打开开关且名单中至少有一个有效名称时，Agent 才能在指定文件夹内写入。首版的配置对连接当前 OpenKeylet 的 Agent 生效。

| 操作 | 放行条件 |
| --- | --- |
| 新增项目 | 目标文件夹在允许名单内 |
| 修改项目 | 从保险库读取的当前文件夹在允许名单内 |
| 移动项目 | 当前文件夹和目标文件夹均在允许名单内 |
| 删除项目 | 首版不提供 MCP 删除工具 |

文件夹按完整名称匹配。「开发」不会自动授权「开发/生产」。添加名称时去除首尾空白，拒绝空名称和重复项。文件夹改名时，用户需要显式更新名单。

写入权限独立于项目的查询、使用和秘密可见性。允许写入不会让隐藏字段变为可读。写入结果只返回项目 ID 和操作状态，错误信息也不能回显写入的秘密值。

## 给 Agent 的写入功能介绍

功能上线后，MCP 的写入工具说明应向 Agent 提供下面的字段清单。下表中的英文标识是现有模块类型，最终调用参数以 MCP 工具声明为准。

只在用户授权的文件夹内新增或修改项目。新增时填写项目名称、类型和目标文件夹，可补充公开用途。公开用途是项目说明，不要在里面存放密码、Token 或私钥。修改时用项目 ID 定位，只提交要更新的字段。无法确定目标项目或必要的凭据信息时，先澄清，避免猜测。

| 要保存的项目 | 可用的预设字段 | 填写说明 |
| --- | --- | --- |
| SSH | 主机或 IP `host`、端口 `port`、账号 `username`、密码 `password`、SSH 私钥 `privateKey`、私钥口令 `passphrase` | 主机填写域名或 IP，端口用整数，标准 SSH 端口为 22。密码登录填写账号和密码。私钥登录填写账号和可用的 SSH 私钥，有口令时写入单独的口令字段。 |
| API | 服务 URL `url`、API 凭据 `apiCredential`，或 Basic 认证所需的账号 `username` 和密码 `password` | 令牌或 API Key 写入 API 凭据。服务 URL 可以包含 API 版本路径，用于保存服务基础地址。 |
| 登录 | 账号 `username`、密码 `password`，按需添加 TOTP 设置密钥 `totp` | 网站匹配使用项目的网站匹配规则。TOTP 字段保存设置密钥。 |
| 扩展字段 | 自定义字段 `customSecret` | 提供字段名和值，例如 `team_id`、`secondary_token`。已有对应预设时优先用预设。自定义字段按秘密加密保存，默认对 Agent 隐藏。 |

例如，在已获授权的「Agent 管理」中新增一条 SSH 项目，可以填项目名「开发机」、主机 `dev.example.com`、端口 `22`、账号 `deploy` 和 SSH 私钥。如果还需要保存服务器所属团队，可以另加自定义字段 `team_id`。团队字段只保存值，不会自动改变 SSH 认证或连接配置。

更新已有项目时，可以替换密码、API 凭据、SSH 私钥和已支持的自定义字段。未提交的字段保留原值，不通过空值隐式删除。替换 SSH 私钥时校验私钥格式和提交的口令，校验失败时保留原凭据。**修改已有项目的连接目标**，如 SSH 主机和端口、API 服务 URL、网站匹配规则，是否开放仍待确认；在确定策略前，Agent 不能假定拥有这项权限。

自定义字段名不能与预设字段或同一项目内的其他字段重复。写入权限不允许改变原字段的 Agent 可见性，也不代表可以读取旧的隐藏值。写入结果只返回项目 ID 和状态。MCP 客户端如果以明文提交新值，该值已经经过调用客户端，请勿在聊天说明中复述。

## 设置界面

在 **设置 → Agent 接入** 的客户端连接设置下方增加 **保险库写入权限**。

```text
保险库写入权限

允许 Agent 新增和修改项目                         [关闭]
允许替换指定文件夹内的密码、Token 和 SSH 私钥。

可写入的文件夹
  Agent 管理                                     [移除]
  开发环境                                       [移除]
  [＋ 添加文件夹]
```

点击「添加文件夹」后，可以选择已有文件夹，也可以输入新名称。点击「添加」才生效，因此可以为还没有项目的文件夹预先授权。点击「移除」立即撤销该名称的写入权限，已有项目和凭据照常保留。

总开关关闭时保留名单，并显示「当前禁止写入」。重新开启后恢复原有授权范围。名单为空时显示「尚未添加可写入的文件夹」，此时写入仍被拒绝。

列表下方说明：「新增项目必须选择可写文件夹。移动项目时，原文件夹和目标文件夹都必须可写。Agent 不能删除项目，写入结果不会返回秘密。」

## 后端检查与验收

每次写入时使用保险库当前的总开关、名单和项目分组做判断。修改操作以保存的项目为准，调用方不能在请求里声明一个可写的原文件夹来取得权限。权限检查和项目写入应在同一次保险库更新中完成，让并发修改或权限撤销不会产生检查与保存之间的空档。

- 默认关闭、名单为空和目标文件夹为空时，MCP 写入均被拒绝。
- 名单只包含「Agent 管理」时，可以在其中新增项目及替换密码、Token 和 SSH 私钥，但不能写入「个人」或「Agent 管理/生产」。
- 把「个人」的项目移动到「Agent 管理」会被拒绝。把「Agent 管理」的项目移到名单外也会被拒绝。原、目标文件夹同时在名单内时允许移动。
- 关闭总开关或移除文件夹后，已连接的 Agent 下一次写入也会被拒绝。
- 成功响应、错误和活动记录均不包含提交的秘密值。桌面端原有编辑功能继续可用。
